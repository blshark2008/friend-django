Как работает синхронизация:

  1. Создайте внутреннюю группу прав в разделе Внутренние группы
  2. Свяжите AD-группу с внутренней группой, создав маппинг
  3. При синхронизации (вручную или автоматически) пользователи, состоящие в AD-группе, получат внутреннюю группу

Команды для ручной синхронизации: 

# Синхронизация конкретного пользователя
python manage.py sync_ad_groups --user username

# Проверка без изменений
python manage.py sync_ad_groups --user username --dry-run

# Массовая синхронизация всех пользователей
python manage.py sync_ad_groups
