О системе

SIEM-система «Друг» предназначена для мониторинга безопасности, инвентаризации оборудования и контроля доступа сотрудников.

Типы событий
Тип Описание
login Успешный вход пользователя на хост
login_unknown Вход неизвестного пользователя (не найден в каталоге)
screen_lock Блокировка / разблокировка экрана
inventory Данные инвентаризации хоста
browser_history История браузера (посещённые URL)
Классификация событий
Критические — немедленная реакция
  • file_changed — изменён критичный файл (/etc/passwd, /etc/shadow, /etc/sudoers)
  • uid0_added — появился пользователь с UID 0 (кроме root)
  • absence_login — вход сотрудника в период отсутствия (отпуск / больничный)
Требуют внимания
  • auth_failed — ≥5 неудачных SSH-входов за интервал (возможный brute-force)
  • suspicious_process — обнаружен подозрительный процесс
  • suid_added — появился новый SUID-файл
  • packages_modified — изменён список установленных пакетов
  • new_port — открыт новый сетевой порт
  • new_connection — новое сетевое соединение
  • new_device — подключено новое устройство
  • firewall_changed — изменены правила фаервола
  • disk_full — диск заполнен (порог 90%)
  • cron_changed — изменён список cron-задач
  • sudo_failed — неудачная попытка sudo
  • kernel_error — ошибка ядра Linux
  • login_unknown — вход неизвестного пользователя
Информационные
  • login, logins_2d, logins_month — входы пользователей
  • agent_alive — агент работает (heartbeat)
  • inventory — данные инвентаризации
  • updates_pending — требуют обновления пакетов
  • browser_history — история браузера
  • screen_lock_log — блокировки / разблокировки экрана
  • sudo_used — использован sudo
  • account_changed — изменение учётной записи
  • parsec_events — события Parsec
Алерты отсутствия

Если сотрудник входит в систему в период отпуска/больничного, автоматически создаётся алерт. Алерт можно подтвердить (acknowledge) с добавлением комментария.

API для агентов

Агенты отправляют данные на следующие эндпоинты:

Эндпоинт Метод Описание
/siem/api/ingest/ POST Приём событий (логины, алерты и т.д.)
/siem/api/inventory/ POST Приём снимков инвентаризации
/siem/api/login-history/ POST История входов
/siem/api/extended-host/ POST Расширенная информация о хосте
